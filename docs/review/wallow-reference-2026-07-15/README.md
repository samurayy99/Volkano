# Wallow Living-World Reference

Source: `https://wallow-bath-body-63.aura.build/`
Captured on desktop and mobile for product-direction study.

## What matters

- the background remains alive throughout the vertical journey
- the content scrolls as a clear narrative layer rather than replacing the world
- motion, depth, atmosphere, and content feel like one continuous experience
- the mobile version preserves immersion instead of collapsing into a generic stacked page

## How it applies to LENOX

This principle belongs to GRAVITY, LENOX's canonical home. GRAVITY should use its own environment, materials, motion, content, and persistent LENOX staging.

The reference is not a surface, layout, asset, or art direction to copy. ATELIER, SIGNAL, and later worlds must not inherit the same fixed-background composition merely because GRAVITY uses it.
