THE BLINK

His visor is the established light source, so the world's light dies with his eyes. Full darkness is the cover; the atomic swap hides inside it; the target's own light performs the reveal. Preparation always completes before the eyes close — the blink never waits on loading.

Live / Authored boundary

Everything the visitor sees is live matter. Collapse and blink run entirely in the existing engine and DOM. Authored media is reserved for optional baked environment assets — never a motion carrier, never a seam.

Per Codex: "fully live" means a deterministic GPU flight choreography (exclusive creation kernel, rift-flight pattern), masked as fluid by curl noise — not a physically balanced orbit.

Typography boundary

Particle mass announces; DOM resolves. Particles condense into line masses and letter shadows; the final readable contours always come from pre-mounted, pre-measured DOM revealed on the same master scalar.

Fonts load while First Contact is still visible. The blink never waits on font discovery.

Honest fallbacks

Reduced motion: beats 02–04 skipped; brief dark hold; identical semantic end state, no longer wait.

Device loss mid-collapse: under cover, one controlled reinit or an honest, fully formed static GRAVITY — never a resumed broken simulation.

After Arrival the full solver retires; 2–4k dust particles, light breathing, and camera parallax carry the permanent living environment inside a real frame budget.
